\section{Inventario reproducible de datos y productos}
\label{anexo:b}

Este inventario resume archivos presentes en el repositorio al momento de la revisión. Las rutas se expresan desde la raíz del proyecto; el detalle vigente se encuentra en cada directorio.

\subsection{Tablas intermedias}
\label{anexo:b_intermedio}

\texttt{datos/intermedio/} contiene diez tablas derivadas del flujo de preparación:
\begin{itemize}[nosep]
\item \texttt{contexto\_1PM.csv}; \texttt{contexto\_1V.csv}; \texttt{control\_nacional.csv}.
\item \texttt{hogares\_1HM\_2HM.csv}; \texttt{ipm\_municipal\_ancho.csv}.
\item \texttt{persona\_demo\_17PM.csv}; \texttt{persona\_social\_5PM.csv}.
\item \texttt{viviendas\_6V.csv}; \texttt{viviendas\_8V.csv}; \texttt{viviendas\_10V.csv}.
\end{itemize}

\subsection{Bases de trabajo}
\label{anexo:b_trabajo}

\texttt{datos/trabajo/} contiene nueve archivos, incluidos \texttt{demografico\_1PM\_completo\_largo.csv}, \texttt{denominadores\_edad\_quinquenal.csv}, \texttt{denominadores\_municipales.csv}, \texttt{indicadores\_municipales\_base\_total.csv}, \texttt{indicadores\_municipales\_base\_valida.csv}, \texttt{ipm\_municipal\_ancho.csv}, \texttt{matriz\_pca\_base\_valida.csv}, \texttt{matriz\_pca\_z.csv} y \texttt{matriz\_pca.csv}. La matriz es candidata: no equivale a un IVS ni demuestra que se haya ejecutado PCA.

\subsection{Verificación de consolidados}
\label{anexo:b_verificacion}

\texttt{resultados/verificacion\_consolidados/} contiene seis productos: \texttt{chequeos\_consistencia.csv}, \texttt{cobertura\_municipal\_por\_hoja.csv}, \texttt{discrepancias.csv}, \texttt{inventario\_hojas\_columnas.csv}, \texttt{mapa\_llaves.csv} y \texttt{universo\_municipal\_maestro.csv}. El universo incluye códigos territoriales y no debe rotularse como 1.122 municipios.

\subsection{Resultados y auditoría}
\label{anexo:b_base_trabajo}

\texttt{resultados/base\_trabajo/} conserva especificaciones, estadísticas descriptivas, diagnósticos de aptitud, correlaciones, análisis de no respuesta y archivos de control. Entre los productos centrales están \texttt{especificacion\_indicadores.csv}, \texttt{estadisticos\_indicadores.csv}, \texttt{varianza\_indicadores.csv}, \texttt{diagnosticos\_aptitud.csv}, \texttt{kmo\_por\_indicador.csv}, \texttt{correlaciones\_pares.csv}, \texttt{sensibilidad\_nr.csv}, \texttt{validaciones.csv} y \texttt{crosswalk\_enlace.csv}. Consulte el directorio para el inventario actualizado.

\texttt{resultados/auditoria\_estadistica/} contiene salidas de auditoría, incluido \texttt{09\_resumen\_auditoria.csv}. Los diagnósticos apoyan la revisión, pero no sustituyen la decisión metodológica sobre las variables ni constituyen una estimación del índice.

\subsection{Scripts}
\label{anexo:b_scripts}

Los scripts reproducibles principales están en \texttt{R/}. Consulte sus archivos vigentes para conocer la configuración, las etapas de construcción y auditoría, y las funciones auxiliares. Se evita fijar aquí una lista de pruebas o productos generados que no haya sido verificada contra el estado actual del repositorio.
