\textbf{Notas:}
\begin{itemize}
    \item Los 7 primeros conforman la matriz candidata provisional para PCA.
    \item Los siguientes 6 (nivel educativo a hacinamiento) se calculan para descripción y validación cruzada; quedan fuera de PCA por solapamiento directo con IPM.
    \item \texttt{hogares\_con\_adultos\_60mas} tiene dirección pendiente (correlación negativa con IPM).
    \item \texttt{IPM\_Municipal} no entra al PCA; es criterio de validación externa.
    \item \texttt{sin\_gas\_red\_publica} y \texttt{sin\_internet} tienen techo alto (prevalencia alta en muchos municipios); evaluar discriminación.
    \item \texttt{estrato\_1\_2}: MSA bajo ($\approx 0,414$); decisión de inclusión pendiente.
    \item \texttt{17PM}: verificar si es asistencia escolar (duplica Inasistencia IPM) o nivel educativo.
\end{itemize}
